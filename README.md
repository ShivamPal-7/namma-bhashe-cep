# Namma Bhashe — Local Language Digital Learning Resources

A basic web platform built as part of a Community Engagement Project (CEP), aimed at delivering digital learning resources in local languages to teachers and learners.

## About
This project was developed for Group 2's CEP topic: *Local Language Digital Learning Resources* — creating multimedia educational content in English and regional languages.
